# 阅读MAO更新日志
## ––– 2026/10/20 –––
* 阅读器弹层统一管理：换源、书源、图片、书签等弹层改为栈式叠放，关闭时只收起最上层，返回键与手势不再一次关掉多层
* 书源详情弹层改为纵向布局，书源名、书源类型与操作项从上到下排列，长书源名不再挤压按钮
* 修复修改书源后回填时机不对导致的弹层状态错乱：只对当前打开的书源弹层回填，处理完立刻清空待回填标记
* 朗读修复：段落间的静音不再重建本章合成任务，纯符号段落不再被跳过
* 朗读修复：段落恢复播放时保留原有停顿，不再从段首重来
* 修复系统 TTS 引擎初始化没有超时上限导致听书整章卡在第一句的问题：引擎未安装、被系统回收或初始化失败时按超时退出，不再占住后续每一句的合成
* 听书下载：点击后立刻显示「进行中」，进度条与已完成章数更新更及时
* 全文搜索：正则搜索加超时保护，复杂正则与超长正文不再把界面卡死，超时后返回已完成的结果
* 全文搜索：结果缓存按「书籍＋关键词＋替换规则」收敛，连续搜索不同关键词不再串结果
* 排版修复：角色名胶囊与整串标点不再把一行顶出空洞
* 排版修复：英文等西文断行时保留行末空格，不再出现单词被粘在一起

## ––– 2026/10/19 –––
* 书架多选移除「反选」「下载缓存」按钮，保留全选、分组、私密与删除
* 修复详情页下拉刷新会取消单本私密标记的问题：刷新后保存书籍时保留数据库中的私密状态
* 修复换源后阅读页仍按初始书籍地址判断会话过期、卡在加载占位页的问题
* 图片点击区域改为实际绘制范围，行内图与整图都能点中；支持图片地址参数里的 pclick 与大小写字段，段落规则点击动作暂时提示不支持
* 修复高亮规则九宫格在半透明背景和自定义切分比例下的接缝变深与切割线，九宫格比例范围放宽到 0 到 1
* 修复发现页分类点选后内容不刷新、分类变更后页面不跟随的问题
* 外观设置新增「阅读界面共享元素动画」开关，关闭后进入阅读器使用渐变过渡
* 阅读器笔记与文本选择菜单避让键盘和安全区，位置变化时平滑移动
* 多角色朗读：关闭多角色时旁白不再顶替引擎默认发音人；开启时章标题由旁白朗读，并跟随正文旁白一起退备用音色
* 角色记忆与人物列表在一次分配后保持一致，别名与简介随记忆更新；AI 分配角色窗口可直接切换当前模型
* 多角色朗读保留用户手动编辑与已配置的章标题旁白，角色记忆可持久保存

## ––– 2026/10/18 –––
* 外部 HTTP TTS 兼容修复：实时朗读、试听、预合成与流式读取共用同一套源脚本、Cookie、登录检查与源级并发限制；修复孤儿音色、外部目录导出与备份恢复的数据一致性，备份额外保存 HTTP 音色表
* 修复朗读运行中控制指令重复请求前台启动导致的超时崩溃：暂停、恢复、切换段落、定时等指令改用普通服务启动，播放时显式声明媒体播放前台类型
* 朗读系列优化：新增电池优化引导与设置入口；系统 TTS 的语速、音高在初始化后按最新设置应用，角色音色结束后回到默认音色
* 朗读播放页支持快捷设置章节定时与切换音色
* 滚动翻页上下边距修正：滚动视口改为固定裁剪，提示页排版计入页眉页脚，正文不再滚进页眉页脚
* 条漫优化：页宽比更新切回主线程；跨章滚动锚点优先当前章图片；返回上一章时定位到该章最后一页
* 修复通过「添加网址」、链接添加或浏览详情新增漫画时，书籍类型没有按书源识别而被存成文本的问题：新书在入库前按书源类型初始化，固定书籍类型默认开启保持不变；已存成文本的旧书仍需在书籍信息编辑里手动改类型

## ––– 2026/10/17 –––
* 缓存命名与图片缓存整理：章节目录与正文统一为「MAO-章节标题」（`MAO-第1话 你好啊/`、`MAO-第1话 你好啊.nb`），章内图片仍按序编号（`MAO-001.jpg`）；漫画按章内页码、文本阅读插图按章节落盘，同章重复图片只算一张，刷新图片时该 URL 的各章副本一起更新
* 导出新增 zip 格式：只打包已缓存内容、不联网抓取，压缩包内一章一个目录、章内图片平铺，可直接作为漫画导入；未缓存的章节只保留自己的章节名空目录，`images/` 层、`.online`、`.downloads`、`.tmp` 不写进包
* 导出设置新增「缓存目录」：按起始章/结束章限定导出范围（留空为不限），txt / epub / zip 三种导出统一按它过滤章节
* 阅读器「离线缓存」对话框改名「缓存选择」：起始章与结束章并排一行、沿用当前章与总章数做默认值，范围非法时确定按钮不可点
* 缓存管理每本书新增「导出zip」「缓存目录」：导出 zip 先选目标文件夹（系统选择器或手动输入路径）、导出结束提示「导出成功」或具体失败原因；「缓存目录」按目录里的 1-based 起止章缓存，超出范围自动收敛
* 本地漫画（zip / cbz / 目录导入）从书架与详情页都能进漫画阅读器，详情页按图片所在目录显示章节数，导入页点压缩包这一行可直接「添加到书架」；修复漫画 zip 添加书架失败、导入后详情页「共 0 章 / 加载目录失败」
