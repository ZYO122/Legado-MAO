# 阅读MAO更新日志

## ––– 2026/11/13 –––
* 菜单体系统一：详情页 ⋮、顶栏、设置行、多选悬浮栏与各列表项菜单改用同一套入口（AppActionMenu / AppChoiceDropdown / AppAnchoredPanel），Material / Miuix / Mochi / COUI 四种引擎共用锚点与弹层
* 设置行下拉改为受控弹层，锚点统一到右侧取值区；设置项与弹窗在不同引擎下不再错位
* 详情页 ⋮ 菜单保持本地顺序：编辑 / 登录 / 自定义按钮 / 设置源变量 / 设置书籍变量 / 拷贝书籍 URL / 同步 WebDAV / 上传 WebDAV / 拆分长章 / 清理缓存 / 阅读日志 / 删除提醒 / 允许更新 / 私密书籍 / 独立关闭阅读记录
* 详情页「私密书籍」与「允许更新」同款：文案固定，只用勾选表示当前状态
* 主题：COUI 引擎改用原生悬浮按钮（FAB），修复首次进入页面时透明，恢复拖拽形变并固定白色图标
* 主题：除 Material 外，其余主题的滚动标签栏补齐边缘渐隐
* 高亮规则：文字、背景、边框、下划线各新增一栏夜间颜色，阅读时按当前模式取色，规则弹窗可分别预览白天与夜间

## ––– 2026/11/12 –––
* 缓存维护：支持清理孤立章节缓存与按章节重算字数，整本重算完成后再汇总整书字数；批量处理时可取消，并显示被跳过的书与原因
* 新增本地 Markdown 阅读：支持导入 .md/.markdown，按标题自动切章，正文图片与链接可用
* 阅读器支持同章跨页选中文字，动作菜单新增「扩展到下一页」；跨页选择可在设置中关闭
* 优化 iOS 仿真翻页的渲染性能与资源生命周期
* 视频支持本地文件播放；剧集切换时保持全屏方向；带请求头的本地 MPD 自动补 DASH 类型
* 主题新增 Miuix HyperOS 4 玻璃组件（玻璃顶栏、标签页与下拉菜单，需 Android 13+，可在主题设置开启）
* 主题新增 COUI 引擎（ColorOS 风格，需 Android 14+），现可选 Material / Miuix / Mochi / COUI
* 修复开启 Mochi 主题时的运行期崩溃
* 大图预览与详情页的图片保存改为后台压缩与写入相册，保存时不再卡界面
* 本地书支持行内图片与行内链接，点击可跳转
* 标签页（TabRow）OS4 样式收尾：阴影、圆角与各引擎边距统一；Material 下尾部按钮保留 16dp 边距
* 修复深色主题下 AI 聊天输入框光标颜色不可见
* Markdown 书籍的图片统一走共享缓存目录，避免章节切换后重复下载

## ––– 2026/11/10 –––
* 修复本地漫画文件夹被当成文件读取导致打不开（EISDIR），目录导入的漫画在书架、详情与阅读器里都能正常进入
* 本地漫画目录授权失效或目录为空时可以重新选择文件夹；混合压缩包（既有书又有图片）仍按「从包内选书」处理，纯图片压缩包按漫画入库
* 桌面快捷方式「最后阅读」支持本地漫画
* 修复本地漫画图片路径含空格或中文时封面与正文图加载失败
* 修复打开、退出阅读界面时书架整片卡顿：共享封面圆角改为绘制期取值，转场不再逐帧重建
* 听书下载区分「整章完成 / 部分完成 / 未校验」，目录与下载面板按状态显示
* 朗读优先播放已下载音频；播放出错不再删除下载区音频；合成失败可整章重试，出错的句子播完再暂停
* 系统 TTS 长文本分段提交，超长段落不再卡住；同一位置重试一次仍失败时暂停并提示
* 朗读翻页与高亮跟随实际播放位置，倍速与缓冲时更准
* 切书时不再把阅读进度写到另一本书，朗读进度事件绑定书籍、章节与会话
* 加载中的暂停可以保留，旧章节的定位任务不再干扰新章节
* 朗读播放浮层显示期间不再抢占阅读器的菜单键与滚轮，浮层退出后设置面板恢复
* 朗读设置子页的返回状态在进程重建后保留
* 书签角标精确贴回页眉底边，不再压住正文
* 本地 EPUB 与 MOBI 支持原书的富文本外观（加粗、强调、颜色等语义样式）
* 横屏时正文避让系统侧边导航栏
* 恢复备份时保留主题、配色、字体、卡片圆角/边框、分隔线与容器背景等偏好，默认忽略悬浮底部栏偏好

## ––– 2026/11/09 –––
* 恢复备份时不再因换源快照删除本机在架书：同一作品已有在架副本时，只恢复书源已在架的行，其余备份行跳过；本机只有临时副本时才采用云端唯一的在架副本，避免误删本机较新的阅读进度
* 修复主题引擎从 Mochi 切回 Material 时崩溃：主题引擎下拉改用独立窗口弹窗，避免切换时销毁菜单触发测量异常
* 顶栏按钮的液态玻璃与页面模糊拆成独立开关：Mochi 可单独控制顶栏按钮玻璃与滚动边缘模糊，Miuix 新增顶栏按钮液态玻璃（需 Android 13 及以上）
* Miuix 顶栏与悬浮底栏接入背景模糊与胶囊折射，Mochi 顶栏改用自身玻璃表面；主界面、发现、详情与朗读胶囊按当前引擎选择背板
* 主题设置里的模糊开关按当前引擎显示，设置搜索会隐藏当前引擎不可用的项
* 阅读页「更多」→ 其他设置新增「段评弹窗高度」：可选跟随书源或 30/50/70/90/100%，自定义高度会覆盖书源给的弹窗尺寸，只对段评页生效

## ––– 2026/11/08 –––
* 设置新增搜索与定位：覆盖 17 类设置入口、251 条结果，选中后跳到原页面并高亮两次；保留查询与列表位置，条件不满足的设置项会引导到前置入口
* 新增 Mochi 主题：Compose 引擎可选 Mochi（默认仍为 Material），带配色、字体、玻璃背板与 Mochi 顶栏、导航底栏、弹窗与基础控件
* 新增「导航动画」与「文字动画级别」设置，弹层、阅读菜单与朗读面板统一动画与间距，主界面支持 Mochi 转场动画
* 漫画缓存导出支持 CBZ 与文件夹两种形态：书架管理与缓存管理共用同一格式设置，一章一个 `MAO-章节名` 目录，只导出已缓存的原图
* 漫画导出支持起止章范围；未缓存或没图的章节只留一个带章节名的空目录，范围内一张图都没有时报错且不留下空包
* 书架管理导出格式只保留 txt 与 epub，zip 不再作为书籍导出格式
* 缓存管理的小说导出改为整本一个 txt，章节按目录顺序接排、章名作小标题，只写已缓存章节
* 导入页支持直接加入纯图片压缩包：点 CBZ 或漫画 zip 即整包作为本地漫画入库，文件选择器也能识别 CBZ
* 修复「一个目录一页」的条漫在导入或回读时被合并成一章的问题
* 导出复制原图期间持有缓存租约，避免在线图片被缓存清理时导出缺页
* 本地漫画：本地导入的漫画暂不支持缓存导出，会给出提示而不是生成空目录

## ––– 2026/11/07 –––
* 安装包瘦身：移除端侧漫画翻译运行时（ONNX Runtime、ML Kit OCR 与内置检测模型），通用包缩小约 160 MiB
* 漫画翻译识别改为 AI 视觉识别与云端 OCR，云端支持百度、腾讯、Paddle 公共接口与自建 Paddle 服务
* 漫画设置新增识别、翻译、合成三组说明，点右侧 ⓘ 可查看各方式的成像、计费与回退差别
* 合成方式移除带模型的擦字引擎，抹字固定使用内置快速处理；需要重绘时可改用 AI 图像模型
* 清理仅服务于端侧引擎的模型下载入口与相关测试

## ––– 2026/11/05 –––
* 「离线缓存」弹窗重做：范围改用目录里看到的章号，可一键选「本章之后 / 本章起 / 全书」，显示已缓存章数与本次范围章数，已缓存的章节自动跳过
* 预下载改为翻页后一次性防抖，连续翻页不再逐章等待；缓存失败改为按次数分级退避，整书缓存进度更准
* 书架网格新增「固定列数」与「固定封面宽度」两种模式，关闭固定列数时按封面宽度自动排列
* 批量导入改为分块提交，书架列表刷新加防抖，上千本书导入时不再卡顿
* 订阅源导入弹窗改用 Compose 实现，订阅源网页里可选择本地文件上传
* 同声线朗读预取，修复朗读队列接播
* 修复 EPUB 跨章首图小白边与漫画首帧拉伸
* 修复滚动模式下 EPUB 图片先闪灰再显示，图片缓存容量按设备内存自适应
* 修复英文符号断行与行尾标点越出正文框
* 修复自定义字体加粗丢失、content:// 字体文件被提前关闭
* 修复 iOS 翻页与 Google 翻页的阴影瑕疵，iOS 翻页内核精简
* 修复登录页 WebView 周边圆角离屏残影，并处理 WebView 渲染进程崩溃
* 阅读与听书控件补齐无障碍名称，列表排序会读出当前位置
* 修复书源列表拖拽后顺序与书源排序不同步
* AI 模型配置弹窗改用 Tiny 系列设置项，修复阅读器面板间距
* 设置 → 其他设置新增「更新源」：可选自动（GitHub 优先，失败换镜像）、仅 GitHub、仅镜像，安装包跟随清单命中的链路下载
* 启动时自动检查更新（默认开启，可在「其他设置」关闭），检查超时不再拖住启动流程

## ––– 2026/11/02 –––
* EPUB/MOBI 本地书新增富文本排版：按文档样式还原字号、颜色、粗斜体、对齐、边距、列表与引用，正文内链接可直接跳转
* 搜索、书签、划线、朗读统一按语义正文定位；书源或文件内容变化导致定位失效时会给出提示，不再静默落到错误位置
* 修复阅读器下划线、分隔线超出文字框时被裁掉的问题，波浪线、双线与自定义 SVG 下划线同样适用
* 长按阅读菜单里的「翻译」按钮可确认后重翻当前章节；翻译进行中会拦截，避免新旧译文混排
* 漫画阅读器的加载中与上下章提示文字改用主题色和字级，深色与自定义主题下更清晰
* 漫画翻译面板重排：顶栏改为「重新排版」和「翻译/重译本章」，诊断入口移到设置区，诊断面板改为卡片布局并直接展开几何预览
* 漫画翻译的「清除」改为描边按钮；思考强度回到基础设置组，单本书也能直接调整
* 修复详情页作者为空时多出一行空白的问题

## ––– 2026/10/31 –––
* 新增「视频」书源类型：书源编辑里可选，视频书源的书可加入书架，书架显示视频类型标签
* 新增视频播放页：卷/集两级选集，支持 HLS 播放；切后台自动暂停（缓冲中也暂停），横竖屏与配置变化不中断播放
* 视频播放支持画中画与悬浮小窗，退到后台由前台服务保活，返回应用后恢复画面
* 视频播放会话下沉到 VideoPlay 统一托管；加入书架后预取详情与目录，RSS 文章里的视频也能直接播放
* 视频播放页菜单按书源能力显示：支持书源登录、自定义按钮与编辑书源菜单；目录切换改为事务化，手势条区域留白适配
* 详情页分类标签可点击跳转发现页；作者名按逗号拆成多个可点击标签（点按搜索、长按更多）；kind 标签先校验链接格式再拆分
* 新增书源级翻页参数 pageParam，发现页翻页可使用书源自定义参数；兜底逻辑只对标签跳转的运行时地址生效
* 发现页网格改为瀑布流布局，封面按原图比例自适应
* 修复批量导入预览列表遇到重复条目崩溃：列表改用 entryId 作 key
* 漫画新增翻译、OCR、图像修复与阅读器工具的可配置项：翻译引擎（含 Google 翻译）、本地与云端 OCR、图像修复、面板检测与字号自适应排版
* 漫画设置面板分类 tab 移到底部，点击区域改为整屏配置
* 阅读器点击区域设置改为格子内下拉选择，修复与「更多」面板的层级冲突
* 修复漫画相邻章插入后翻页被拽回：位置按实际显示的页保持，只有页身份失效才回退

## ––– 2026/10/29 –––
* 新增三种翻页效果：iOS 仿真、Google 仿真、视差，可在全局阅读样式和单书翻页菜单里选择，共用原有的翻页速度挡位
* 快速连翻不再闪回或停在翻页后的偏移状态；翻页过程中图片加载完成也不会掉回静态快照
* 新增缓存维护（设置 → 下载缓存设置 → 其他设置）：可扫描并清理查不到对应章节的孤立章节缓存，也能为缺少字数的在线书籍重算字数
* 修复版本升级时内置默认数据（书源、TTS、目录规则、词典规则）的迁移可能被跳过的问题，导入失败会在下次启动重试
* 书架分组弹窗的勾选跟随当前分组，切换分组不再显示上一次的选中状态
* 备份纳入当前阅读排版引用的背景图与字体，恢复后自动修正失效路径
* 导入气泡包 zip 时改为流式识别，大包不再整包读入内存
* 段评气泡的图片选项解析按图片地址缓存，长章节滚动更省内存

## ––– 2026/10/28 –––
* 段评气泡改为可导入导出的「气泡包」：包内包含 SVG 模板、日间/夜间与普通/强调四色、尺寸缩放，以及可引用的字体与图片资源，可在设置里新建、编辑、复制、删除、导出和导入，带实时预览；模板不可用时退回默认胶囊
* 段评取数补齐：支持书源在图片选项里写显示文本（displayText/num/count/text/label），也支持从 createSvg2 脚本参数、内嵌 SVG、图片 type 与 showcmt 语义里读评论数
* 评论数达到 99+ 或三位数时自动使用强调色（红色），普通评论用黑色，不再受书源是否声明强调状态影响
* 修复评论数为 0 时仍显示段评气泡的问题
* 阅读样式页新增气泡入口，可直接切换气泡包或切回跟随书源图，换包后立即重新排版
* 气泡包按包目录整树纳入备份，恢复为整树事务替换、失败回滚，已删除的包不会随备份复活；当前生效的包不在备份里时回落内置并切回跟随书源图；文件管理器与网络导入遇到含 bubble.json 的 zip 时按气泡包处理，不再当书籍/排版包
* 气泡样式收敛为「跟随书源 / 指定气泡包」两态：旧的内置样式与自定义 SVG 在读取时统一并入当前气泡包
* 发现页顶栏改为单书源搜索入口，书源选择改为可筛选的底部面板
* 修复英文撇号导致配音胶囊只剩两个的问题，AI 分配角色窗口新增复制按钮
* 修复发现页切换布局与网格数量时重复订阅状态、界面偶发闪动的问题

## ––– 2026/10/25 –––
* 阅读主题列表弹窗：阅读菜单「主题」页最右侧新增入口，支持网格/流式两种布局切换、拖动排序、批量删除与置顶，主题可整包导入导出或单独分享
* 高亮规则新增边框样式（颜色、粗细、圆角），色块填充跟随同一圆角；修复规则预览渲染错位，预览示例句加长到能折行

* 搜索、发现、详情页封面按原图宽高比显示，默认固定 5:7，可在设置里关掉

* 排版修复：开标点连同后面的拉丁单词整体换行，不再把单词拆到下一行
