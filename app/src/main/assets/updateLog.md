# 阅读MAO更新日志
## ––– 2026/10/16 –––
* 支持平板 / 折叠屏分屏，外观设置里可选多栏模式
* 书架支持标签来源设置：自定义标签 / 书源标签 / 字数可分别开关
* 书架搜索按钮支持长按进入筛选，再次长按收起
* 阅读器新增阅读时闪烁效果
* 滑动翻页恢复对斜划的响应
* 整图也识别 src 尾随 JSON 里的点击区域
* 翻页模式下点朗读从当前页开始
* 常挂朗读弹层打开时当前章每次重组都重读
* 支持听书与阅读不同书籍
* 朗读修复：切下一章不再取消脚下的准备作业、准备中重复点播放不再重起、分配覆盖层出错不再带走整章准备
* 角色补音改为随机，音色被删自动重挑
* 音色池兼容 TTS Server 导出的第二种层级，导入确认页可选来源引擎包名
* 添加音色的搜索框不再越筛越小
* 处理 Legado Reader 插件的重复书籍；Web 服务保留当前状态并返回 JSON 错误
* 内置默认数据与 web 资源改用 APK 路径

## ––– 2026/10/15 –––
* 应用图标换成品牌猫
* 开屏改为整屏自绘层（可开关/换图，系统开屏同色无缝）
* 首次启动页头像换成品牌猫图标
* 关于页头像换成品牌猫图标
* 关于页新增「更新日志」入口并精简内置日志
* 包名与应用名改为 MAO 系列
* 版本改为 3.26.1，正式/测试 versionCode 各自独立递增
* 预下载拆分为「向前 / 向后」，相邻章预取跟随设置
* 系统分组精简为「全部 / 更新失败」
* 详情页菜单重排，新增按书关闭阅读记录（切换后立即生效，复制书籍保留该开关）
* 发现页支持跳转页码（按 URL 规则判断书源能否翻页），改名后仍按书源地址识别书架
* 缓存目录按章节组织，漫画目录正确显示已缓存图标
* 缓存升级后保留旧版章节正文与图片；文本渲染 / 看图 / Web 等只持 URL 的调用方也能取到章节原图；刷新图片会同步该 URL 的全部缓存副本
* 目录重扫缓存时使用当前书目录名；按章节的重名标题偏好写入 nr 文件
* 修复漫画 / 条漫：预取方向、相邻页 1px 白缝、跨章抖动
* 漫画视口锚点可跨进程重建保存，列表重建期间不再整章乱跳；关闭预取时在章节边界继续拖动仍会加载相邻章
* 漫画预取数量与阅读设置共享（向前 / 向后）
* 书籍信息新增「我的子标签」：主标签进书架与详情页，子标签只在详情页显示
* 固定书籍类型改为默认开启，书籍更新不再覆盖类型
* 书架布局默认改为手动排序 / 升序 / 列表（竖屏）
* 书架分组选择改为居中卡片：标题居中、每项一个气泡，启用分组少时用小卡；网格模式保留标签行与展开按钮
* 分组管理更灵活：新建分组默认不占用书架分组，最多同时显示 16 个
