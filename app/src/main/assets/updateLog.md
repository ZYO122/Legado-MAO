# 阅读MAO更新日志
## ––– 2026/10/31 –––
* 新增「视频」书源类型：书源编辑里可选，视频书源的书可加入书架，书架显示视频类型标签
* 新增视频播放页：卷/集两级选集，支持 HLS 播放；切后台自动暂停（缓冲中也暂停），横竖屏与配置变化不中断播放
* 视频播放支持画中画与悬浮小窗，退到后台由前台服务保活，返回应用后恢复画面
* 视频播放会话下沉到 VideoPlay 统一托管；加入书架后预取详情与目录，RSS 文章里的视频也能直接播放
* 视频播放页菜单按书源能力显示：支持书源登录、自定义按钮与编辑书源菜单；目录切换改为事务化，手势条区域留白适配
* 详情页分类标签可点击跳转发现页；作者名按逗号拆成多个可点击标签（点按搜索、长按更多）；kind 标签先校验链接格式再拆分
* 新增书源级翻页参数 pageParam，发现页翻页可使用书源自定义参数；兜底逻辑只对标签跳转的运行时地址生效
* 发现页网格改为瀑布流布局，封面按原图比例自适应
* 修复批量导入预览列表遇到重复条目崩溃：列表改用 entryId 作 key
* 漫画新增翻译、OCR、图像修复与阅读器工具的可配置项：翻译引擎（含 Google 翻译）、本地与云端 OCR、图像修复、面板检测与字号自适应排版
* 漫画设置面板分类 tab 移到底部，点击区域改为整屏配置
* 阅读器点击区域设置改为格子内下拉选择，修复与「更多」面板的层级冲突
* 修复漫画相邻章插入后翻页被拽回：位置按实际显示的页保持，只有页身份失效才回退

## ––– 2026/10/29 –––
* 新增三种翻页效果：iOS 仿真、Google 仿真、视差，可在全局阅读样式和单书翻页菜单里选择，共用原有的翻页速度挡位
* 快速连翻不再闪回或停在翻页后的偏移状态；翻页过程中图片加载完成也不会掉回静态快照
* 新增缓存维护（设置 → 下载缓存设置 → 其他设置）：可扫描并清理查不到对应章节的孤立章节缓存，也能为缺少字数的在线书籍重算字数
* 修复版本升级时内置默认数据（书源、TTS、目录规则、词典规则）的迁移可能被跳过的问题，导入失败会在下次启动重试
* 书架分组弹窗的勾选跟随当前分组，切换分组不再显示上一次的选中状态
* 备份纳入当前阅读排版引用的背景图与字体，恢复后自动修正失效路径
* 导入气泡包 zip 时改为流式识别，大包不再整包读入内存
* 段评气泡的图片选项解析按图片地址缓存，长章节滚动更省内存

## ––– 2026/10/28 –––
* 段评气泡改为可导入导出的「气泡包」：包内包含 SVG 模板、日间/夜间与普通/强调四色、尺寸缩放，以及可引用的字体与图片资源，可在设置里新建、编辑、复制、删除、导出和导入，带实时预览；模板不可用时退回默认胶囊
* 段评取数补齐：支持书源在图片选项里写显示文本（displayText/num/count/text/label），也支持从 createSvg2 脚本参数、内嵌 SVG、图片 type 与 showcmt 语义里读评论数
* 评论数达到 99+ 或三位数时自动使用强调色（红色），普通评论用黑色，不再受书源是否声明强调状态影响
* 修复评论数为 0 时仍显示段评气泡的问题
* 阅读样式页新增气泡入口，可直接切换气泡包或切回跟随书源图，换包后立即重新排版
* 气泡包按包目录整树纳入备份，恢复为整树事务替换、失败回滚，已删除的包不会随备份复活；当前生效的包不在备份里时回落内置并切回跟随书源图；文件管理器与网络导入遇到含 bubble.json 的 zip 时按气泡包处理，不再当书籍/排版包
* 气泡样式收敛为「跟随书源 / 指定气泡包」两态：旧的内置样式与自定义 SVG 在读取时统一并入当前气泡包
* 发现页顶栏改为单书源搜索入口，书源选择改为可筛选的底部面板
* 修复英文撇号导致配音胶囊只剩两个的问题，AI 分配角色窗口新增复制按钮
* 修复发现页切换布局与网格数量时重复订阅状态、界面偶发闪动的问题

## ––– 2026/10/25 –––
* 阅读主题列表弹窗：阅读菜单「主题」页最右侧新增入口，支持网格/流式两种布局切换、拖动排序、批量删除与置顶，主题可整包导入导出或单独分享
* 高亮规则新增边框样式（颜色、粗细、圆角），色块填充跟随同一圆角；修复规则预览渲染错位，预览示例句加长到能折行
* 详情页关联书籍移到简介下方；书源没有关联规则时按作者搜索兜底
* 阅读页 AI 对话入口可携带当前书与章节上下文，菜单里可开关
* 搜索、发现、详情页封面按原图宽高比显示，默认固定 5:7，可在设置里关掉
* 配音页与人物列表不再只列 80 人；AI 分配角色时会带上「过了几章没开口」和下一章开头

* 内置词典规则更新为汉典，清理失效的百度汉语规则
* 条漫修复：整章拼接的超长图改为拆段渲染，修复尺寸溢出崩溃
* 排版修复：开标点连同后面的拉丁单词整体换行，不再把单词拆到下一行
* 修复引号跨段时角色气泡把整章排版打挂的问题
* 修复详情页简介纯文本分支二次转义，& < > 显示成 HTML 实体的问题
* 分页失败时日志带上异常信息与栈顶，便于定位
* 备用启动图标入口不再重复避让输入法，弹出键盘时内容不被顶上两次

## ––– 2026/10/17 –––
* 缓存命名与图片缓存整理：章节目录与正文统一为「MAO-章节标题」（`MAO-第1话 你好啊/`、`MAO-第1话 你好啊.nb`），章内图片仍按序编号（`MAO-001.jpg`）；漫画按章内页码、文本阅读插图按章节落盘，同章重复图片只算一张，刷新图片时该 URL 的各章副本一起更新

* 阅读器「离线缓存」对话框改名「缓存选择」：起始章与结束章并排一行、沿用当前章与总章数做默认值，范围非法时确定按钮不可点

* 本地漫画（zip / cbz / 目录导入）从书架与详情页都能进漫画阅读器，详情页按图片所在目录显示章节数，导入页点压缩包这一行可直接「添加到书架」；修复漫画 zip 添加书架失败、导入后详情页「共 0 章 / 加载目录失败」
